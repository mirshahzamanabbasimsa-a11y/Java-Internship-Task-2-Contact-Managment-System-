**Contact Management System**
A simple, professional desktop application built in Java to manage personal or business contacts. This project was developed as part of a Internship task, focusing on core Java programming, GUI development, and collection-based data handling.
The application allows users to add, view, search, and delete contacts through a clean and intuitive graphical interface — all within a single, well-structured Java file.

**Features**
Add Contacts – Add new contacts with name and phone number, with input validation to prevent invalid entries
Display Contacts – View all saved contacts in a clean, tabular GUI layout
Search Contacts – Real-time search by contact name as you type
Delete Contacts – Remove contacts with a confirmation prompt to prevent accidental deletion
Data Validation – Ensures names contain only valid characters and phone numbers follow a proper format
In-Memory Storage – Contact data managed dynamically using a collection (ArrayList)
User-Friendly GUI – Built with Java Swing for a clean, professional desktop interface
Single-File Implementation – Entire application structured in one Java file for simplicity and easy review

**Technologies Used**
Language: Java (JDK 21)
GUI Framework: Java Swing
Data Structure: ArrayList (Java Collections Framework)
IDE: Visual Studio Code (with Java Extension Pack)
Version Control: Git & GitHub
